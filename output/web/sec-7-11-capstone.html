    Section 7.11 Putting It Together: Capstone Case Study

    You now have the tools you need to solve a problem that requires storing, manipulating, and accessing a collection of data. Let’s put it all together with a program that reads records of object data from a file, sorts the records, and produces a map overlay that can be rendered in a browser.
    🔗

    Subsection 7.11.1 The Problem

    Imagine you are given a map of trails and landmarks along with a text file of the names and (x, y) coordinates for the sites. You’re asked to write a program that will read the data in, alphabetize it by name, and present the list of sites to the user. The user will choose a site, and your program will produce an HTML document that displays the map with the user’s site choice highlighted.
    🔗
    
    Official National Park Service map of Boston National Historical Park and surrounding neighborhoods, including Cambridge, Beacon Hill, Downtown Boston, the North End, and Charlestown. The red Freedom Trail line and blue Black Heritage Trail line are drawn across the street grid with landmark labels.
    🔗
    Park map of Boston National Historic Park retrieved from https://npgallery.nps.gov/HFC/Cartography.
    🔗
    A record of site information is organized as the site name on the first line (text), the number of points making up the site (integer), and then the x, y coordinate for each point, each pair on its own line. For example:
    🔗
    African Meeting House
1
470 690
    This site is a landmark and is therefore represented by only one coordinate. The output HTML is boilerplate, except for three insertions that your program will make from the chosen site. The name as the title and heading of the page:
    🔗
    <title>African Meeting House</title>
<h1>African Meeting House</h1>
    And the list of points to either highlight with a red circle (for a landmark) or a yellow line (for a trail):
    🔗
    const points = [

    Subsection 7.11.2 Decomposing the Problem

    The problem we’ve been asked to solve has a simple, linear structure. We can decompose it into four steps, with each implemented as a method:
    🔗
    1. Read the data from the file into a collection
      🔗
      🔗
    2. Sort the collection alphabetically by name
      🔗
      🔗
    3. Present the sorted names to the user and get their choice
      🔗
      🔗
    4. Write the HTML, inserting data from the record (name and points)
      🔗
      🔗
    Considering the data we need to store, we recognize that we already have a Point class that we can use to represent the individual points of a trail or the single point representing a landmark. But how should we represent a site, which is a name and either a single point or an ordered list of points?
    🔗
    A Site class allows us to encapsulate together a name and any non-zero number of Point objects (one to many) into a single object that we can store in a collection of Site objects. Here is a class diagram for Site:
    🔗
    Besides the constructor and accessors for the name and points fields, we include a compareTo method so that Site objects can be sorted by name. The compareTo method takes another Site object as a parameter and returns equivalent values to the String.compareTo method: zero if the name fields are equal, a negative integer if the Site on which the method was invoked is lexicographically before the parameter, and a positive integer if the Site on which the method was invoked is lexicographically after the parameter.

    Subsection 7.11.3 Site Class Implementation

    The Site class is relatively simple, but let’s establish some class invariants to avoid run-time errors:
    🔗
    • The name cannot be null or blank.
      🔗
      🔗
    • The points array cannot be null or empty, as every valid site has at least one point.
      🔗
      🔗
    • No Point within the points array can be null.
      🔗
      🔗
    We must also decide whether the constructor should deep copy the points parameter or alias it. (Because String objects are immutable, we don’t need to copy name.) If we alias points, the Site object shares the exact same array as the code that called the constructor—meaning the caller still holds a reference to the array and its Point objects. That caller could later invoke translate on one of the Point objects, moving it off the correct location on the map, or worse, set an element of the array to null and break our class invariant. We therefore deep copy points in the constructor. Similarly, to protect our class invariant, we’ll return a deep copy of points from getPoints.

    Subsubsection 7.11.4.2 Reading From the File into the ArrayList of Site objects

    Let’s build the sites ArrayList from the file data. The file is organized into an unknown number of records, which we will read one record per iteration of a file-reading loop. At the end of the loop, we’ll have a Site object to store in our ArrayList. Each record begins with a name, so we’ll read the Site name from the file, storing it in a local variable until we’re ready to instantiate our object.
    🔗
    The next line of the file is the number of points associated with the Site. We will use this information to initialize an array of Point to its exact size. We then loop that number of times, reading x, y coordinates, instantiating Point objects, and storing them in the Point array. Once we’ve finished reading the Point data, we can instantiate a Site with the name we read earlier and the Point array.
    🔗
    We will set preconditions on the method that the file name isn’t null and that it’s the name of a text file of Site data in the correct format. This is the updated readSites method, ready to insert in place of our stub:
    🔗
    /**
 * Reads map location data from the file fileName, instantiates Site objects for
 * each record of location data and stores in the returned ArrayList.
 *
 * Preconditions:  fileName != null and fileName is a text file of records formatted as
 *                 location name 
 number of points 
 number of points lines of x y
 * Postconditions: If the file exists, returns an ArrayList of Site objects -- one
 *                 for each record in the file. If it doesn't, returns an empty ArrayList.
 *
 * @param fileName  The name of the file containing location data.
 * @return          An ArrayList of Site objects, one for each record in the file, or
 *                  an empty ArrayList if the file cannot be found or is empty.
 * @throws FileNotFoundException
 */
public static ArrayList<Site> readSites(String fileName) throws FileNotFoundException {
    assert fileName != null : "File name cannot be null";
    ArrayList<Site> sites = new ArrayList<>();
    File siteFile = new File(fileName);
    if (siteFile.exists()) {
        Scanner fileScanner = new Scanner(siteFile);
        while (fileScanner.hasNext()) {
            String name = fileScanner.nextLine();
            int numPoints = fileScanner.nextInt();
            Point[] pointsList = new Point[numPoints];
            for (int i = 0; i < numPoints; i++) {
                int x = fileScanner.nextInt();
                int y = fileScanner.nextInt();
                pointsList[i] = new Point(x, y);
            }
            sites.add(new Site(name, pointsList));
            // Consumes the newline:
            if (fileScanner.hasNextLine()) {
                fileScanner.nextLine();
            }
        }
        fileScanner.close();
    }
    return sites;
}

    Subsection 7.11.5 Sorting and Searching the Site ArrayList

    We’ll next implement sorting the array. If the array is sorted, then we can use a binary search when we search the array for the user’s choice of site to highlight.
    🔗
    We’ll use our selection sort algorithm from before, but this time written to sort Site objects. Because we are comparing objects, we can’t use the relational (< >) operators. We will take advantage of the compareTo method we wrote for Site objects, so the comparison in our algorithm becomes:
    🔗
    (sites.get(j).compareTo(sites.get(minIndex)) < 0)
    Here we get an element at index j, which is a Site, and invoke the compareTo method on it, passing it the element at get(minIndex). These are swapped if the element at j is less than (alphabetically before) the element at minIndex, using the get and set methods.
    🔗
    /**
 * Sorts sites into ascending lexicographical order by site name
 * using selection sort.
 *
 * Precondition:  sites != null and no element of sites is null.
 * Postcondition: The elements of sites are arranged in ascending order
 *                according to Site.compareTo.
 *
 * @param sites  The ArrayList of Site objects to sort.
 */
public static void sortList(ArrayList<Site> sites) {
    assert sites != null : "sites can't be null.";
    for (Site site : sites) {
        assert site != null : "site elements can't be null.";
    }

    for (int i = 0; i < sites.size() - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < sites.size(); j++) {
            if (sites.get(j).compareTo(sites.get(minIndex)) < 0) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            Site temp = sites.get(i);
            sites.set(i, sites.get(minIndex));
            sites.set(minIndex, temp);
        }
    }
}
    Now that our list of sites is sorted, we can implement the getUserChoice method using a binary search. This method will display the site names to the user in the sorted (alphabetical) order and then ask the user for their choice.
    🔗
    Let’s start with the preconditions and postconditions for the method. We can only display the site names if the ArrayList is non-null and contains at least one Site, and if all Site objects have non-null names. We check that there is at least one value in the ArrayList, back in main, before invoking this method, so it will never be invoked if there was a problem reading the file or if the file was empty.
    🔗
    As a postcondition, the method will return a valid index into sites. This means that, within the method, we’ll prompt the user for their choice and then find the choice within the list. If it’s not found, we’ll need to prompt and search again. A binary search ensures that each lookup—whether the name is valid or not—runs in \(O(\log n)\) time.
    🔗
    We therefore have a binary search nested within an input validation loop. The binary search is the same algorithm we presented before, but once again, because we are comparing Site objects, we rely on the compareTo method rather than relational operators.
    🔗
    /**
 * Presents the Site names to the user, obtains the name of the site they
 * want to visit, and returns the index of the chosen site using binary search.
 *
 * Preconditions:  sites != null and has at least one element;
 *                 sites.get(i) != null and sites.get(i).getName() != null
 *                 for 0 <= i < sites.size();
 *                 sites is sorted in ascending order by Site.compareTo.
 * Postconditions: Returns a valid index into sites corresponding to the user's choice.
 *
 * @param sites  A sorted ArrayList of non-null Site objects with size >= 1.
 * @return       A valid index into sites.
 */
public static int getUserChoice(ArrayList<Site> sites) {
    assert sites != null : "sites can't be null.";
    assert sites.size() >= 1 : "sites can't be empty.";

    Scanner stdin = new Scanner(System.in); // For reading user input.
    String choice;                          // The user's choice of site.
    int index = -1;                         // The index of the user's choice.

    // Displays the site names to the user.
    for (Site site : sites) {
        assert site != null : "site can't be null.";
        assert site.getName() != null : "site can't have a null name.";
        System.out.println(site.getName());
    }

    // Obtains the user's choice in an input validation loop.
    while (index == -1) {
        System.out.print("Which site would you like to highlight? ");
        choice = stdin.nextLine().trim();

        // Uses binary search to locate the user's choice in sites.
        int low = 0;
        int high = sites.size() - 1;
        boolean found = false;

        while (low <= high && !found) {
            int mid = (low + high) / 2;
            int cmp = sites.get(mid).getName().compareTo(choice);
            if (cmp == 0) {
                found = true;
                index = mid;
            } else if (cmp < 0) {
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }

        if (!found) {
            System.out.println("Site not found. Please enter a name from the list (case-sensitive).");
        }
    }
    stdin.close();
    return index;
}

    🔗
    /**
 * Writes an HTML file into the working directory that opens boston_map.png
 * and draws a highlight for the given Site (a circle for a single point,
 * or a polyline for multiple points).
 *
 * Precondition:  site != null, site.getName() != null,
 *                site.getPoints() != null, site.getPoints().length > 0,
 *                and fileName != null and is not blank.
 * Postcondition: Creates or overwrites the file named fileName with an HTML5
 *                canvas page displaying boston_map.png and the highlighted
 *                site.
 *
 * @param site      The Site to highlight.
 * @param fileName  The output HTML file name.
 * @throws FileNotFoundException if the output file cannot be created or opened.
 */
public static void writeHTMLFile(Site site, String fileName) throws FileNotFoundException {

    assert site != null : "Site to display cannot be null.";
    assert fileName != null && !fileName.isBlank() : "File name cannot be null or blank.";
    assert site.getName() != null : "Site name cannot be null.";
    Point[] points = site.getPoints();
    assert points != null : "Site cannot consist of null points.";
    assert points.length > 0 : "Site must have at least one point.";

    File outputFile = new File(fileName);
    PrintWriter writer = new PrintWriter(outputFile);

    // Sets up the HTML header.
    writer.println("<!DOCTYPE html>");
    writer.println("<html>");
    writer.println("<head>");
    writer.println("    <title>" + site.getName() + "</title>");
    writer.println("</head>");
    writer.println("<body>");
    writer.println("    <h1>" + site.getName() + "</h1>");
    writer.println("    <canvas id="mapCanvas"></canvas>");

    // Writes the Javascript code.
    writer.println("    <script>");
    writer.println("    const canvas = document.getElementById("mapCanvas");");
    writer.println("    const ctx = canvas.getContext("2d");");

    // Creates a Javascript array of objects called points from the site.
    writer.println("    const points = [");
    for (int i = 0; i < points.length - 1; i++) {
        writer.println("        {x: " + points[i].getX() + ", y: " + points[i].getY() + "},");
    }
    writer.println("        {x: " + points[points.length - 1].getX() + ", y: " + points[points.length - 1].getY() + "}");
    writer.println("    ];");

    // Writes the script to draw the map and highlight the landmark.
    writer.println("    const img = new Image();");
    writer.println("    img.onload = function () {");
    writer.println("        canvas.width = img.width;");
    writer.println("        canvas.height = img.height;");
    writer.println("        ctx.drawImage(img, 0, 0);");

    writer.println("        if (points.length === 1) {");
    writer.println("            // Landmark: draw a highlight ring and center dot");
    writer.println("            ctx.beginPath();");
    writer.println("            ctx.arc(points[0].x, points[0].y, 16, 0, 2 * Math.PI);");
    writer.println("            ctx.strokeStyle = "#dc2626";");
    writer.println("            ctx.lineWidth = 4;");
    writer.println("            ctx.stroke();");
    writer.println("            ctx.beginPath();");
    writer.println("            ctx.arc(points[0].x, points[0].y, 5, 0, 2 * Math.PI);");
    writer.println("            ctx.fillStyle = "#dc2626";");
    writer.println("            ctx.fill();");
    writer.println("        } else if (points.length > 1) {");
    writer.println("            // Trail segment: draw a thick highlighted polyline");
    writer.println("            ctx.beginPath();");
    writer.println("            ctx.moveTo(points[0].x, points[0].y);");
    writer.println("            for (let i = 1; i < points.length; i++) {");
    writer.println("                ctx.lineTo(points[i].x, points[i].y);");
    writer.println("            }");
    writer.println("            ctx.strokeStyle = "#f59e0b";");
    writer.println("            ctx.lineWidth = 6;");
    writer.println("            ctx.lineCap = "round";");
    writer.println("            ctx.lineJoin = "round";");
    writer.println("            ctx.stroke();");
    writer.println("        }");
    writer.println("    };");
    writer.println("    img.src = "boston_map.png";");
    writer.println("    </script>");

    // Close the HTML document.
    writer.println("</body>");
    writer.println("</html>");

    // Closes the PrintWriter so it writes the rest of the stream to the file.
    writer.close();
}
